Кроме вышеприведенных кейсов по работе с датами в SQL, рекомендую ознакомиться с документацией по следующим операторам :

NOW() — Возвращает текущую дату и время.
CURDATE() — Возвращает текущую дату.
CURTIME() — Возвращаем текущее время.
DATE() — Состоит из двух частей даты и времени.
EXTRACT() — Возвращает одно значения даты/времени.
DATE_ADD() — Добавляет до выборки указанное число дней/мину/часов и т.д.
DATE_SUB() — Вычитываем указанный интервал от даты.
DATEDIFF() — Возвращает значение времени между двумя датами.
DATE_FORMAT() — Функция для различного вывода информации о времени.

Вывести из таблицы Advertising топ-5 самых дорогих объявлений, которые имеют статус «Активно» и созданы в 2022 году.

Запрос должен вывести столбцы: advertising_id, amount, created_at, status.
SELECT advertising_id, amount, created_at, status
FROM Advertising 
WHERE status = 'Активно' AND EXTRACT (YEAR FROM created_at) = 2022
ORDER BY amount DESC
LIMIT 5

Здравствуйте, Александра!
EXTRACT - это стандартная функция SQL, которая позволяет извлекать отдельные компоненты (год, месяц, день, час, минуту и т.д.) из значений даты и времени. Она является частью стандарта SQL и поддерживается большинством систем управления базами данных (СУБД), таких как PostgreSQL, MySQL, Oracle, SQL Server и другими.

Синтаксис функции EXTRACT выглядит следующим образом:

1
EXTRACT(component FROM source)
Здесь:

component - это компонент, который вы хотите извлечь из значения даты/времени (например, YEAR, MONTH, DAY, HOUR, MINUTE, SECOND и т.д.)
source - это выражение, возвращающее значение даты или времени, из которого нужно извлечь компонент.
Например, ваш запрос EXTRACT(YEAR FROM created_at) = 2022 извлекает год из столбца created_at и сравнивает его с 2022. Это условие будет истинным для всех строк, где год в столбце created_at равен 2022.
