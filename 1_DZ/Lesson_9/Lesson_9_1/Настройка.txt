Этап 1: Подготовка и скачивание (Обход блокировок)
Вам понадобится учетная запись Qt (Qt Account).

Включите VPN. Выберите любую локацию кроме РФ и РБ (например, Нидерланды, Германия). Это критически важно для начала загрузки и авторизации.

Перейдите на официальный сайт для загрузки Open Source версии: Скачать Qt Online Installer.

Выберите Download for Windows.

Если у вас нет аккаунта Qt, зарегистрируйтесь на этом же сайте (с включенным VPN). Используйте почту на домене .com (например, Gmail), чтобы избежать лишних проверок, хотя .ru часто тоже работает.

Этап 2: Установка Qt
Запустите скачанный файл (например, qt-unified-windows-x64-online.exe). Не выключайте VPN.

Введите логин и пароль от Qt Account.

Установите галочку, что вы используете Qt для личных целей (не коммерческих).

Выбор компонентов (Самый важный шаг): Вам предложат выбрать «Custom Installation» (Выборочная установка). Выберите её.

В дереве компонентов разверните список Qt -> Qt 6.x.x (выберите самую свежую стабильную версию, например, 6.7 или 6.8).

Отметьте галочками следующее:

MinGW 11.2.0 64-bit (или новее) — это компилятор. Рекомендую выбрать его, а не MSVC, чтобы не устанавливать отдельно Visual Studio.

Qt 5 Compatibility Module (на всякий случай).

В разделе Developer and Designer Tools (Инструменты разработчика) убедитесь, что выбраны:

Qt Creator (среда разработки).

CMake (система сборки).

Ninja (ускоритель сборки).

Нажмите «Далее» и дождитесь окончания установки. Путь установки лучше оставить стандартным: C:\Qt. Совет: Когда начнется непосредственно скачивание гигабайтов данных, VPN иногда можно отключить для скорости, но если загрузка прервется — включите снова.

Этап 3: Настройка переменных среды (Для скриншота №2)
Qt Creator настраивает пути внутри себя, но в задании требуют прописать их в системе.

Нажмите Win + R, введите sysdm.cpl и нажмите Enter.

Вкладка Дополнительно -> кнопка Переменные среды....

В блоке Системные переменные (нижнее окно) найдите строку Path и нажмите Изменить.

Вам нужно добавить пути до папки bin компилятора и bin системы CMake. Если вы установили Qt в C:\Qt, пути будут выглядеть примерно так (версии цифр могут отличаться):

Путь к компилятору: C:\Qt\Tools\mingw1120_64\bin

Путь к CMake: C:\Qt\Tools\CMake_64\bin

Нажмите «Создать» и добавьте эти два пути.

Нажмите ОК во всех окнах.

Этап 4: Настройка комплектов в Qt Creator (Для скриншота №3)
Запустите Qt Creator.

Перейдите в меню: Правка (Edit) -> Preferences (Настройки).

В левом меню выберите Kits (Комплекты).

Вкладка Kits. Вы должны увидеть автоматически определенный комплект (например, Desktop Qt 6.7.0 MinGW 64-bit).

Убедитесь, что напротив него нет красных или желтых значков.

В поле Compiler должны быть указаны C и C++ компиляторы (MinGW).

В поле Debugger должен быть указан GDB.

В поле CMake Tool должен быть выбран установленный CMake.

Этап 5: Сборка проекта (Для скриншота №4)
В Qt Creator: Файл -> Новый проект.

Выберите: Application (Qt) -> Qt Widgets Application. Нажмите «Выбрать».

Название: TestProject. Путь: любая папка без русских букв в названии.

System Build: выберите CMake (или qmake, но сейчас стандарт CMake).

Class Information: оставьте по умолчанию.

Kit Selection: поставьте галочку напротив вашего комплекта Desktop Qt ... MinGW ....

Нажмите «Завершить».

Откроется проект. Нажмите зеленую кнопку Run (треугольник) слева снизу или Ctrl+R.

Дождитесь появления пустого окна программы.

Внизу нажмите на вкладку Вывод сборки (Compile Output).

Чек-лист для сдачи задания (Скриншоты)
Теперь, когда все готово, сделайте 4 скриншота для отчета:

Скриншот 1: Корневая папка Qt

Откройте проводник.

Перейдите в C:\Qt.

Сделайте скриншот так, чтобы в адресной строке было видно C:\Qt (или ваш путь), а в папке видны папки версий (например, 6.7.0, Tools, MaintenanceTool).

Скриншот 2: Переменные среды

Откройте окно переменных среды (как в этапе 3).

Откройте редактирование переменной Path.

Сделайте скриншот, чтобы были четко видны добавленные строки с .../mingw.../bin и .../CMake.../bin.

Скриншот 3: Настроенный комплект

В Qt Creator откройте Preferences -> Kits.

Выберите ваш активный комплект (Desktop Qt MinGW).

Сделайте скриншот этого окна. Должно быть видно:

Name: Desktop Qt...

Compiler: MinGW...

Debugger: GDB...

CMake Tool: CMake...

Скриншот 4: Вывод сборки

В Qt Creator после успешного запуска проекта.

В нижней панели переключитесь на вкладку Compile Output (Вывод сборки).

Там должно быть написано что-то вроде Build finished successfully или Exit code: 0. Сделайте скриншот этой области.

Проблема: Ошибка "Installation from this IP address is not allowed" возникает потому, что ваш VPN работает только внутри браузера (как расширение). Установщик Qt — это отдельная программа, она не «видит» ваш браузерный VPN, выходит в интернет напрямую и сервер Qt блокирует ваш российский IP.

«Пропустить» этот шаг нельзя — без входа в аккаунт установщик не даст скачивать файлы.

У вас есть два пути решения. Рекомендую Способ 1, он проще для новичка.

Способ 1: Использовать системный VPN (Самый простой)
Вам нужно установить VPN-клиент, который меняет IP-адрес для всего компьютера, а не только для браузера.

Скачайте бесплатный VPN-клиент для Windows.

Сейчас в РФ более-менее стабильно работают: Planet VPN (версия для ПК, не расширение), Psiphon или Proton VPN (если удастся подключиться, используют протокол Stealth).

Запустите VPN и подключитесь к любой стране (Нидерланды, Германия, США).

Перезапустите установщик Qt.

Закройте окно с ошибкой.

Запустите файл qt-unified-windows-x64-online.exe заново.

Теперь авторизация пройдет успешно.

Важно: Не выключайте VPN, пока не начнется скачивание файлов. Когда пойдет загрузка процентов (Download), VPN можно попробовать отключить для скорости, но если скачивание оборвется — включите обратно.

Способ 2: Использование зеркала (Если VPN не помогает)
Если даже с VPN возникают проблемы, можно попробовать запустить установщик через командную строку с указанием "зеркала" (альтернативного сервера), который может быть не заблокирован.

Нажмите Win + R, введите cmd и нажмите Enter.

Перетащите файл установщика (qt-unified...exe) прямо в черное окно консоли — там появится путь к файлу.

Нажмите «Пробел» и допишите в конце строки: --mirror https://mirrors.tuna.tsinghua.edu.cn/qt

Вся строка должна выглядеть примерно так: C:\Downloads\qt-unified-windows-x64-online.exe --mirror https://mirrors.tuna.tsinghua.edu.cn/qt

Нажмите Enter.

Это заставит установщик качать файлы с китайского университетского зеркала, которое обычно не блокирует РФ, но для этапа входа в аккаунт (Login) вам все равно потребуется хоть какой-то VPN, так как проверка логина идет через главные сервера Qt.

Способ 3: "Продвинутый" (Без VPN и смс — aqtinstall)
Если совсем ничего не помогает, есть способ установить Qt без официального графического установщика и без входа в аккаунт, используя Python-скрипт. Это полностью легально (Open Source) и не требует VPN.

Установите Python (с галочкой "Add to PATH").

Откройте консоль (cmd) и введите: pip install aqtinstall

Создайте папку C:\Qt.

В консоли введите команды по очереди (это скачает Qt 6.7, MinGW и QtCreator):

Скачивание самой библиотеки и компилятора: aqt install-qt windows desktop 6.7.2 win64_mingw -O C:\Qt

Скачивание Qt Creator: aqt install-tool windows desktop tools_qtcreator -O C:\Qt

Скачивание CMake: aqt install-tool windows desktop tools_cmake -O C:\Qt

Скачивание Ninja: aqt install-tool windows desktop tools_ninja -O C:\Qt

После этого у вас будет папка C:\Qt с тем же содержимым, что и при обычной установке, и вы сможете настроить пути (переменные среды) и выполнить задание.

Мой совет: Попробуйте сначала Способ 1 (установить программу Planet VPN или Psiphon на компьютер). Это быстрее всего приведет вас к цели.
